## 1. Сброс до заводских настроек
Перед началом настройки необходимо сбросить роутер до заводских параметров:
1. Найдите на корпусе углубление, над которым написана буква **«F»**.
2. Возьмите скрепку, булавку или другой тонкий предмет.
3. Нажмите на скрытую кнопку внутри углубления.

## 2. Подключение по SSH и смена пароля
1. Подключитесь к роутеру по протоколу SSH:
   * **IP-адрес:** `192.168.1.1`
   * **Порт:** `22`
2. Авторизуйтесь в системе:
   * **Логин:** `admin`
   * **Пароль:** `password`
3. Сразу после входа система потребует сменить пароль. Введите команду:
   ```
   password <ваш_новый_пароль>
   ```

## 3. Переход в режим конфигурации
Для внесения изменений перейдите в режим конфигурации:
```text
configure
```

## 4. Настройка DHCP-сервера
1. Создайте пул адресов (в примере используется имя `deadpool`):
   ```
   ip dhcp-server pool deadpool
   ```
2. Укажите адрес сети:
   ```
   network 172.16.4.0/28
   ```
3. Задайте диапазон выдаваемых IP-адресов:
   ```
   address-range 172.16.4.2-172.16.4.14
   ```
4. Укажите IP-адрес шлюза по умолчанию:
   ```
   default-router 172.16.4.1
   ```
5. Укажите DNS-сервер:
   ```
   dns-server 172.16.4.1
   ```

## 5. Настройка моста (Bridge)
Создайте мост и назначьте ему IP-адрес:
1. Задаем ip:
   ```
   bridge 1
   ip address 172.16.4.1/28
   ```
2. Отключите фаервол на этом порту:
   ```
   ip firewall disable
   ```
> *💡 Примечание: в исходном тексте на этом шаге создается `bridge 1`, а в следующем шаге (NAT) используется `bridge 2`. Убедитесь, что номера мостов соответствуют вашей физической схеме подключения.*

## 6. Настройка NAT (Source NAT)
Настройка выхода локальной сети в публичную сеть (SNAT). 
1. Создайте объект-группу локальной сети «LAN» и укажите разрешенный диапазон адресов:
   ```
   object-group network LAN
   ip address-range 172.16.4.2-172.16.4.14
   ```
2. Создайте набор правил SNAT. Правила включают проверку адреса источника на принадлежность к пулу «LAN» и его трансляцию:
   ```
   nat source
   ruleset SNAT
   to interface bridge 2
   rule 1
   match source-address LAN
   action source-nat interface
   enable
   ```

##7. Настройка DNS:
   ```
   domain lookup enable
   domain name-server 8.8.8.8
   domain name-server 1.1.1.1
   ```

## 8. Сохранение конфигурации
Чтобы применить и сохранить внесенные изменения, выйдите из режима конфигурации и выполните команды подтверждения:
```
exit
commit
confirm
```
